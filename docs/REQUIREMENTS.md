# 카툰플러스 요구사항 명세서 (Requirements Specification)

본 문서는 기능(FR) 및 비기능(NFR) 요구사항의 명세 및 구현 상태를 관리하는 표준 기준 문서임.

> **기준 스펙**: 서울대입구역점(`snu`), 잠실점(`jamsil`), 홍대점(`hongdae`) 3개 직영 지점 전면 운영 전환 및 ADR-0001 ~ ADR-0010 의사결정 반영 완료.

---

### 요구사항 ID 체계

| 구분            | Prefix               | 예시         |
| :-------------- | :------------------- | :----------- |
| 기능 요구사항   | `FR-<도메인>-###`    | FR-BOOK-001  |
| 비기능 요구사항 | `NFR-<카테고리>-###` | NFR-PERF-001 |

| 코드  | 도메인                    | 설명                                                                                          |
| :---- | :------------------------ | :-------------------------------------------------------------------------------------------- |

| BOOK  | 도서 검색 & 카탈로그      | 공백 무시 검색, 초성 검색, 도서/작가명 검색, 텍스트 상세 카드, 30일 신간 배지, 무효 쿼리 차단 |
| INV   | 도서 재고 & CSV 관리      | 개별 도서 등록/수정, 3개 지점 CSV 파싱 및 안전 가져오기, 영구 삭제(복구 미지원)               |
| BCAST | 매장 안내 방송            | 정적 음원 6종 프리셋 및 업로드 음원 방송, 전역 스케줄러, 방송 이력 7일 롤링 보존              |

### 우선순위 기준

- **상**: 핵심 사용자/직원 흐름 필수 요건 (서비스 불가결)
- **중**: 제품 완성도 및 운영 편의 개선 요건
- **하**: 추후 확장 및 고도화 대상

### 구현 단계(Phase) 정의

| Phase | 단계명                         | 범위                                                                                                                                                                                     | 상태 |
| :---- | :----------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--: |
| 1단계 | MVP                            | 반응형 도서 검색(공백무시/초성) + 텍스트 카드 + 30일 신간 + 비회원 도서신청 + 검증 게임/이벤트 + 메뉴/요금제 + 직원 승인제 + Caspio CSV 가져오기 + 정적 6종 프리셋/예약 방송 + $0 인프라 | 완료 |
| 2단계 | 다지점 확장 & 운영 안정화      | 잠실점·홍대점 CSV 파싱 지원 + URL 지점 라우팅 + Staff 소속 지점 격리 + 비로그인 전역 방송 스케줄러(ADR-0010) + 20개 라우트 SSG 사전 빌드                                                 | 완료 |
| 3단계 | 매장 운영 자동화 (향후 로드맵) | 매장 평면도(Floor Map) 서가 핀포인트 + 지도 길찾기 API 연동 + 직원 디지털 근태 관리 + 좌석/룸 실시간 이용 현황                                                                           | 예정 |

## 2. 비기능 요구사항 (Non-Functional Requirements)

| ID           | 카테고리        | 요구사항명             | 상세 기준                                                                                                                                        |
| :----------- | :-------------- | :--------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------- |
| NFR-COST-001 | 비용 최적화     | 월 고정 운영비 $0      | Cloudflare Pages + Supabase Free Tier 조합으로 도메인 실비 제외 월 고정비 0원 유지.                                                              |
| NFR-PERF-001 | 성능            | 초고속 도서 탐색       | 검색어 입력 후 결과 렌더링 300ms 이내, 서가 위치 확인 3초 이내 지원.                                                                             |
| NFR-RESP-001 | 반응형 UX       | 모바일 뷰포트 최적화   | 모바일 접속 시 가로 스크롤 및 잘림 현상 방지, 터치 친화적 하단 내비게이션 제공.                                                                  |
| NFR-DES-001  | 디자인 시스템   | 브랜드 일관성 준수     | 브랜드 옐로우(#FED943), 차콜(#1E1E1E), 마스코트 10종 및 선형 SVG 아이콘 한정 사용.                                                               |
| NFR-DES-002  | 웹 접근성       | 동작 줄이기 지원       | `prefers-reduced-motion` 시스템 설정 시 장식 애니메이션 축소 및 비활성화.                                                                        |
| NFR-SEC-001  | 보안 & 개인정보 | 비회원 개인정보 최소화 | 고객 도서 신청 시 개인정보 미수집, 직원 비밀번호 단방향 해시(BCrypt) 저장.                                                                       |
| NFR-REL-001  | 신뢰성          | 예약 방송 송출 안정성  | 카운터 브라우저 활성 상태에서 예약 방송 정시 송출 및 실행 이력 기록 ([ADR-0010](docs/adr/0010-unauthenticated-broadcast-and-7day-retention.md)). |
