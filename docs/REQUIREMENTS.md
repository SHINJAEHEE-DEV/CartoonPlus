### 우선순위

| 값 | 의미 |
| --- | --- |
| 상 | 핵심 사용자/직원 흐름 필수, 없으면 서비스 성립 불가 |
| 중 | 제품 완성도 및 운영 편의에 필요, 일부 지연 가능 |
| 하 | 추후 확장/고도화 대상 |

### 구현 단계(Phase) 정의

| Phase | 정의 | 범위 |
| --- | --- | --- |
| MVP (1단계) | 서울대입구역점 운영 전환 필수 | 반응형 도서 검색(공백무시/초성) + 텍스트 카드 + 30일 신간 + 비회원 도서신청 + 검증 게임/이벤트 + 메뉴/요금제 + 직원 승인제 + CSV 안전 가져오기 + 매장 전용 6종 프리셋/예약 방송 + $0 인프라 |
| Phase2 (2단계) | 시각화 & 멀티 지점 | 매장 평면도(Floor Map) 서가 핀포인트 + 카카오/네이버 지도 API 연동 + 잠실점 멀티 지점 활성화 |
| Phase3 (3단계) | 매장 운영 자동화 | 직원 디지털 출석 체크(근태 관리) + 파트별 업무 체크리스트 + 매장 룸/좌석 실시간 이용 현황 연동 |
