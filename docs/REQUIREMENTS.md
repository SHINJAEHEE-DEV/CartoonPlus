**카툰플러스 (CartoonPlus Cafe) 요구사항 명세서**

기능/비기능 요구사항을 표 형태로 관리합니다. ID는 `FR-<도메인>-###`, `NFR-<카테고리>-###` 형식을 사용합니다.

### 요구사항 ID 규칙

| 구분 | Prefix | 예시 |
| --- | --- | --- |
| 기능 요구사항 | `FR-<도메인>-###` | FR-BOOK-001 |
| 비기능 요구사항 | `NFR-<카테고리>-###` | NFR-PERF-001 |

### 도메인 코드

| 코드 | 도메인 | 설명 |
| --- | --- | --- |
| AUTH | 관리자 인증 | 직원/관리자 로그인, 세션/토큰 관리, 로그아웃 (일반 손님은 로그인 불필요) |
| BOOK | 도서 검색 | 공백 무시 검색, 초성 검색, 장르/완결 필터, 텍스트 전용 상세 카드 |
| INV | 도서 재고 관리 | 개별 도서 등록/수정, 서가 번호/권수 관리, 엑셀 일괄 업로드 |
| BCAST | 매장 안내 방송 | 원클릭 프리셋 TTS 방송, 커스텀 텍스트 즉시 방송, 송출 상태 표시 |
| REQ | 도서 입고 신청 | 손님 희망도서 입고 신청, 관리자 신청 목록 조회 및 상태 관리 |
| STORE | 매장 & 콘텐츠 | 지점 선택(서울대입구/잠실), 닌텐도/Xbox/보드게임, F&B 메뉴, 요금제, 매장 안내 |
| OPS | 매장 운영 자동화 | 평면도 서가 핀포인트, 지도 API 연동, 직원 출석 체크, 업무 가이드 |

### 우선순위

| 값 | 의미 |
| --- | --- |
| 상 | 핵심 사용자/직원 흐름 필수, 없으면 서비스 성립 불가 |
| 중 | 제품 완성도 및 운영 편의에 필요, 일부 지연 가능 |
| 하 | 추후 확장/고도화 대상 |

### 구현 단계(Phase) 정의

| Phase | 정의 | 범위 |
| --- | --- | --- |
| MVP (1단계) | 초기 릴리스 필수 기능 | 반응형 도서 검색(공백무시/초성) + 텍스트 카드 + 지점별 메뉴/게임/매장 안내 + 직원 TTS 방송 + 도서 재고/엑셀 관리 + 월 운영비 0원 인프라 |
| Phase2 (2단계) | 시각화 & 외부 연동 | 매장 평면도(Floor Map) 서가 핀포인트 시각화 + 카카오 지도/네이버 지도 API 연동 + 신간 자동 입고 알림 |
| Phase3 (3단계) | 매장 운영 자동화 | 매장 직원 출석 체크(근태 관리) + 파트별 업무 가이드 & 일일 체크리스트 + 매장 룸/좌석 실시간 이용 현황 연동 |

### 역할 정의

| 구분 | 권한 | 설명 |
| --- | --- | --- |
| 일반 이용자 | GUEST (비회원) | 별도 로그인 없이 사이트에 접속하여 도서 검색, 엔터테인먼트 목록, F&B 메뉴, 매장 정보를 자유롭게 열람하는 손님 |
| 매장 직원 | STAFF | 매장 포스/PC에서 로그인하여 도서 재고 수정, 신규 도서 등록, 엑셀 일괄 업로드, 매장 안내 방송 송출 권한을 가진 직원 |
| 점주/총괄 관리자 | ADMIN | STAFF 권한을 포함하며, 지점 기본 정보, 메뉴/게임 카탈로그, 공지/이벤트 등록 및 시스템 설정을 총괄하는 관리자 |

| **멀티 지점 정책** |   • 서울대입구역점, 잠실점을 단일 사이트에서 탭/셀렉터로 전환 지원하며, 향후 신규 지점 확장이 가능한 데이터 구조를 유지한다. |

## 📖 용어 정의

| 용어 | 정의 |
| --- | --- |
| **정규화 검색 (Whitespace-Agnostic)** | 검색어와 도서명의 띄어쓰기/특수문자를 제거하여 '체인소 맨'과 '체인소맨'을 동일하게 매칭하는 검색 처리 방식 |
| **서가 위치 뱃지 (Shelf Location)** | 도서가 매장 내 실제로 꽂혀있는 위치 코드 및 구역 텍스트 (예: `A-03 서가 (소년만화 구역)`) |
| **Web Speech API (TTS)** | 웹 브라우저에 내장된 음성 합성 엔진으로, 추가 비용 없이 텍스트를 고품질 한국어 음성으로 변환 |
| **MVP (1단계)** | 도서 검색, 매장/메뉴 안내, 직원 TTS 방송, 도서 재고 관리를 포함한 초기 릴리스 필수 기능 세트 |
| **Phase2 / Phase3** | 매장 평면도 시각화, 지도 연동, 직원 근태/업무 가이드 등 순차적으로 확장하는 기능 세트 |
