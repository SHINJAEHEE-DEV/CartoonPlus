# 8. 스태프 콘솔 모바일 반응형 내비게이션 및 2단 카드 레이아웃

- **상태**: 승인됨 (Accepted)
- **결정일**: 2026-09-17
- **참여**: 시니어 PM, 프론트엔드 개발팀

## 맥락 (Context)
카툰플러스의 스태프 콘솔(`/staff/*`)은 매장 데스크톱 PC(1920x1080 / 1440x900) 중심의 240px 좌측 사이드바 레이아웃으로 설계되었다. 그러나 현장 매니저 및 직원이 매장 서가 점검, 음료 제조 중 모바일 기기(아이폰/갤럭시) 및 태블릿으로 접속할 때 다음과 같은 레이아웃 붕괴가 발생했다:
1. **내비게이션 과밀**: 화면 너비 860px 이하에서 사이드바가 상단 가로 스크롤로 전환되며 로고, 역할 배지, 지점 선택 드롭다운, 7개 메뉴 탭, 계정 관리, 로그아웃 버튼이 한 줄로 나열되어 조작성이 훼손됨.
2. **리스트/테이블 찌그러짐**: 도서 재고 관리(`InventoryPage`), 도서 입고 신청(`BookRequestsPage`), 계정 관리(`AdminAccountsPage`)의 단일 라인 Flex/Grid 아이템이 좁은 모바일 뷰포트에서 줄바꿈 오류 및 버튼 겹침 현상 발생.
3. **터치 타깃 부실**: 장르 버튼, 삭제 버튼, 상태 변경 드롭다운 등의 터치 영역이 30px 미만으로 좁아 오터치 발생.

## 결정 (Decision)
1. **StaffShell 모바일 내비게이션 구조**:
   - 데스크톱(>860px)에서는 기존의 240px 좌측 사이드바를 유지한다.
   - 모바일(<=860px)에서는 상단 컴팩트 헤더(`staff-mobile-header`: 로고, 매장명, 관리자 지점 전환 칩, 햄버거 메뉴 버튼)와 우측 슬라이드오버 Drawer(`staff-drawer`)로 분리한다.
   - Drawer 내부에는 권한 배지, 7개 전체 운영 메뉴, 관리자 계정 관리, 고객 화면 보기, 로그아웃 버튼을 통합 배치한다.
2. **반응형 2단 카드 스택 (Card Stack)**:
   - 도서 재고, 입고 신청, 계정 목록의 아이템을 모바일에서 `staff-item-row` (상단: 상태 배지 + 제목 + 세부정보, 하단: 상태 드롭다운 및 액션 버튼 우측 정렬) 구조로 재배치한다.
3. **1열 풀위드 폼 (Single-Column Form)**:
   - 모바일에서 모든 신규 등록 및 수정 폼(`staff-form-grid`)을 1열 스택으로 전환하고, 최소 터치 타깃 40~44px를 보장한다.
4. **모바일 지점 선택기**:
   - `StaffStoreSelector`에 `variant="header"`를 추가하여 상단 헤더에서는 컴팩트 칩으로 노출되고, 터치 시 화면 중앙/바텀 오버레이 팝오버로 지점을 안정적으로 전환할 수 있도록 한다.

## 결과 및 효과 (Consequences)
- **장점**:
  - 모바일 현장 업무 시 본문 작업 영역(도서 검색, 재고 등록, 방송 등)이 시원하게 확보됨.
  - 한 손 터치 조작 시에도 오터치 없이 상태 변경 및 삭제가 가능해짐.
  - iOS Safe Area Inset 대응으로 하단 제스처 바와의 간섭 해결.
- **주의사항**:
  - 모바일 드로어가 열렸을 때 페이지 스크롤 및 포커스 관리가 안정적으로 유지되어야 한다.
