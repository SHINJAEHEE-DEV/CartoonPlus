# React + Vite 기반 SPA 및 Mock-First 개발 전략 채택

GitHub Pages 정적 호스팅을 통한 월 고정 운영비 $0 달성 및 클라이언트 사이드 고속 도서 검색(공백 무시/초성 정규화)과 Web Speech TTS의 원활한 동작을 위해 **React + Vite + TypeScript + Tailwind CSS / Shadcn UI** 스택을 채택합니다. 초기 개발 단계에서는 인메모리/로컬 Mock 데이터를 우선 구축하여 핵심 검색 알고리즘과 전체 사용자/관리자 UI를 신속히 검증한 후 Supabase 클라이언트를 점진적으로 연동합니다.
