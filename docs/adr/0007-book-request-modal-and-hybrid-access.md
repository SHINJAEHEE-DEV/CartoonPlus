# 모달 기반 도서 입고 신청 전환 및 다중 접점 가시성 극대화

## Context

카툰플러스 도서 검색 서비스에서 사용자가 찾고자 하는 도서가 없을 때 입고 신청으로 연결되는 진입점이 검색 결과 0건 하단으로만 제한되어 있었으며, 클릭 시 별도 독립 페이지(`/book-request`)로 이동하여 검색 맥락이 끊기는 UX 문제가 존재하였다.
또한 모바일 사용자가 많은 매장 환경에서 빠르게 도서 입고를 신청할 수 있는 상시적이고 직관적인 진입점과 모달 인터페이스가 필요하였다.

## Decision

1. **도서 입고 신청 모달(`BookRequestModal`) 도입**:
   - 페이지 이동 없이 검색 화면 내에서 바로 팝업되는 네오 브루탈리즘 스타일의 대화형 모달 컴포넌트를 구축한다.
   - 검색창에 입력 중이던 검색어가 있을 경우 도서명(Title) 필드에 자동으로 프리필(Pre-fill)한다.
   - 개인정보보호 및 신청 장벽 해소를 위해 연락처 등 개인정보는 일절 수집하지 않으며, 신청 완료 시 마스코트 축하 뷰와 함께 원래 검색 화면으로 자연스럽게 복귀할 수 있도록 한다.
2. **다중 접점 하이브리드 가시성(CTA) 강화**:
   - 도서 검색 상단에 "찾으시는 도서가 없으신가요? 1분 입고 신청하기" 배너 카드 배치.
   - 검색 결과 0건 시 검색어를 담은 즉시 모달 열기 버튼 연동.
   - 모바일/데스크톱 화면 우측 하단에 상시 고정된 플로팅 액션 버튼(FAB, `[📖 입고 신청]`) 제공.
   - 데스크톱 헤더 우측 액션 바에 입고 신청 버튼 배치.
3. **독립 URL(`/book-request`)과의 듀얼 모드 공존**:
   - 외부 링크 공유, QR 코드 스캔, 직접 URL 접근 시에는 동일한 완성도의 단독 페이지(`BookRequestForm`)로 서비스하여 호환성을 유지한다.

## Consequences

- 손님이 검색 도중 페이지 이탈 없이 1분 만에 도서 입고를 신청할 수 있어 전환율과 만족도가 극대화된다.
- 모바일 하단 네비게이션을 복잡하게 변경하지 않으면서도 상시 플로팅 버튼(FAB)과 상단 배너를 통해 어디서나 즉시 접근 가능하다.
