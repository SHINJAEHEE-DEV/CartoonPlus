# 핵심 검색 알고리즘, 인증 및 라우팅 구조 결정

번들 최적화를 위해 외부 의존성 없이 유니코드 자모 분해 공식에 기반한 **자체 경량 한글 초성/정규화 모듈**을 구현하여 공백 무시 및 초성 도서 검색을 처리합니다. 관리자 인증은 추후 Supabase Auth로 1:1 교체 가능한 인터페이스 기반의 **로컬 인증 컨텍스트**로 관리하며, `react-router-dom` 기반의 **다중 라우트 SPA**(`/`, `/search`, `/entertainment`, `/menu`, `/store`, `/admin`) 구조를 채택합니다.
