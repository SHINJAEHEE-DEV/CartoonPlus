# Supabase로 운영 데이터와 직원 인증을 중앙 관리한다

서울대입구역점은 다음 주 일요일 GitHub Pages에서 운영을 전환하며, 도메인 비용 외 정기 운영비 0원을 유지한다. 여러 고객·직원 기기에서 도서 재고, 입고 신청, 게임, 이벤트, 예약 방송과 직원 계정을 같은 데이터로 관리해야 하므로 Supabase의 PostgreSQL, Auth, Storage, Row Level Security를 채택한다. 고객은 공개 정보만 읽고, 승인된 직원은 운영 정보를 관리하며, 관리자는 직원 계정 승인과 비활성화 권한을 추가로 가진다.
