# 지점 URL과 지점 범위 권한을 기준으로 다지점 운영을 한다

카툰플러스는 여러 지점의 재고와 콘텐츠를 한 Supabase 프로젝트에 저장하지만, 현재 화면과 일부 RPC는 `snu` 지점에 고정되어 있다. 고객은 URL의 지점 식별자(`/stores/:slug`)로 현재 매장을 선택하고 화면 상단에서 바꾸며, 일반 직원은 소속 지점만 수정하고 관리자는 전체 지점을 관리하도록 결정한다. 자동 위치 추정이나 전역 지점 혼합 조회 대신 이 방식을 택해 잘못된 매장 정보 노출과 직원의 타 지점 수정 위험을 막고, 추가 서버 비용 없이 공유·검색 가능한 지점별 URL을 유지한다.

## Consequences

모든 지점 종속 조회·쓰기에는 선택한 `store_id`가 필요하며, CSV 가져오기·도서 검색·매장 콘텐츠·메뉴·게임·이벤트·방송·도서 신청을 함께 전환해야 한다. RLS와 RPC는 일반 직원의 `staff_accounts.store_id`를 확인하고, 수동 방송 실행 기록에도 지점 식별자를 남겨야 한다.
