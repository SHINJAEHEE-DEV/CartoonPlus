# Triage Labels

스킬들은 5가지 표준 triage 역할을 기준으로 동작합니다. 이 파일은 해당 역할들을 이 저장소의 issue tracker에서 사용하는 실제 라벨 문자열에 매핑합니다.

| Label in mattpocock/skills | Label in our tracker | Meaning (의미)                           |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 메인테이너의 이슈 검토가 필요함          |
| `needs-info`               | `needs-info`         | 작성자로부터 추가 정보가 필요함          |
| `ready-for-agent`          | `ready-for-agent`    | 명세가 완료되어 AFK agent가 작업 가능함  |
| `ready-for-human`          | `ready-for-human`    | 사람이 직접 구현해야 함                  |
| `wontfix`                  | `wontfix`            | 처리하지 않음                            |

스킬에서 특정 역할을 언급할 때(예: "apply the AFK-ready triage label"), 이 표의 해당 라벨 문자열을 사용합니다.

실제 사용하는 라벨 어휘에 맞게 오른쪽 열을 수정할 수 있습니다.
