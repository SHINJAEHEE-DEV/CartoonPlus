```
[프로젝트 개요]
- 프로젝트명: 만화카페 카툰플러스 매장 운영 자동화 및 웹 플랫폼 전면 리뉴얼
- 운영 지점: 홍대점, 잠실점, 서울대입구역점 (총 3개 지점 실운영)

- 주요 목표: UX 개선, 도서 검색 정밀화, 매장 운영 수기 업무 자동화, 인프라 고정비 $0화
```

### 1) 프로젝트 추진 배경 및 문제 정의 (Problem)
- **도서 검색 UX 저하**: 기존 웹사이트는 공백/특수문자가 정확히 일치하지 않으면 검색이 되지 않았으며, 동일 도서가 권수별로 중복 노출되어 가독성과 정보 탐색 효율이 심각하게 저하됨.
- **파편화된 매장 운영 업무**: 안내방송은 번역기 TTS 수기 입력, 도서 관리는 Caspio SaaS, 입고 신청은 수기 노트로 분산되어 피크 시간대 근무자 업무 과중 유발.
- **고정 인프라 비용 발생**: 적은 트래픽 규모 대비 유료 외주 DB SaaS(Caspio) 구독료(연 약 30~36만 원)가 지속 발생하고 있었음.

### 2) 기획 및 의사결정권자 설득 (Planning & Persuasion)
- **PoC 프로토타입 제시**: 모바일/데스크톱 UI 시안과 핵심 검색 엔진 동작 프로토타입을 직접 제작하여 대표님께 시연.
- **비용 $0 아키텍처 제안**: 매장 일일 트래픽 및 데이터 갱신 빈도를 정량 분석하여, Cloudflare Pages Edge 배포 및 Supabase Serverless Free Tier를 조합한 무비용 인프라 구조를 증명함으로써 대표님의 비용 우려를 해소하고 3개 지점 전면 전환 승인 획득.

### 3) 핵심 기술 구현 및 아키텍처 설계 (Key Actions)

#### 1. 1:N 데이터 모델 정규화 및 검색 엔진 최적화: 검색 실패율 0%
- **문제**: 기존 단일 평면 테이블로 동일 도서가 권수별로 중복 노출되어(약 5,000건) 검색 가독성이 저하되고, 띄어쓰기가 일치하지 않으면 도서 검색이 실패함.
- **접근**: 데이터베이스를 도서 메타(`books`)와 지점별 권수/위치(`book_inventory`)로 1:N 분리 정규화하고, 공백 제거 정규화(`replace`) 및 한글 초성/부분 일치 검색 RPC 함수를 구현함.
- **성과**: 중복 도서 데이터를 통합하고 도서 검색 실패율 0%를 달성함. 검색 화면 내 서가 번호 뱃지 및 구역 배치도 UI를 제공하여 카운터 도서 위치 문의를 70% 감소시킴.

#### 2. 웹 성능 최적화 및 Post-Build SSG: LCP 17.4s -> 2.5s, SEO 100점
- **문제**: 고용량 외부 이미지와 렌더 블로킹 폰트로 인해 모바일 LCP가 17.4초에 달하고 Lighthouse 모바일 성능 점수가 37점에 머물러 매장 현장 사용성이 크게 저하됨.
- **접근**: 이미지를 WebP로 변환해 정적 번들링하고 `fetchpriority="high"`를 적용함. 고정 비율 AspectRatio 박스로 레이아웃 흔들림(CLS 0.009)을 방어하고, 빌드 시점 지점별 정적 HTML을 사전 생성하는 커스텀 SSG 스크립트를 구축함.
- **성과**: 모바일 LCP 17.4s → 2.5s (85.6% 단축), Lighthouse 성능 점수 37점 → 76점 향상, 지점별 포털 검색엔진 노출을 위한 SEO 점수 100점 만점을 달성함.

### 5) 정량적 비즈니스 성과 (Results)
- **TCO 100% 절감**: 연 36만 원 상당의 유료 SaaS 구독료 제거 (운영비 $0 달성)
- **성능 개선**: Lighthouse Mobile Performance 37점 → 76점 (+105%), 모바일 LCP 17.4s → 2.5s (85.6% 단축)
- **업무 효율화**: 일일 매장 안내방송 및 도서 등록 업무 소요 시간 90% 감축 (일 30분 → 3분)
- **검색 정밀도**: 공백 무시 및 초성 지원으로 도서 검색 실패율 0% 달성

## 3. 면접 대비 핵심 스토리라인 (STAR Framework)

### Q1. 현장 문제를 발견하고 기획부터 운영까지 완수한 경험 (카툰플러스)
- **Situation**: 기존 웹사이트는 도서 검색이 불편하고 관리 비용이 매달 발생하고 있었으나, 대표님 입장에서는 기존 시스템을 교체할 때 추가 개발비나 일정 부담을 우려함.
- **Task**: 기존 시스템의 한계점을 명확히 짚고, 추가 비용 지출 없이 매장 운영 효율을 획기적으로 높일 수 있음을 증명해야 했음.
- **Action**: 
  1. 사용자 웹·모바일 및 관리자 콘솔 화면 디자인 와이어프레임 시안과 개선 기획서를 직접 작성하여 제안함.
  2. 일일 트래픽 및 데이터 갱신 주기를 산출하여 Serverless Free Tier 기반의 '인프라 비용 $0 아키텍처'를 수치로 제시함.
  3. 향후 지점 확장 시 추가 비용이 발생하지 않는 구조임을 설명함.
- **Result**: 대표님의 전폭적인 신뢰를 얻어 3개 지점 전면 개편 승인을 획득하고 성공적으로 배포함. 배포 후 직원 VOC를 수렴해 6종 원클릭 프리셋을 1일 만에 추가 배포함.

### Q2. 대안을 다 써보고 나서 최적의 방식을 고르는 엔지니어링 경험 (CatchEat)
- **Situation**: 참여 챌린지 501개 기준 목록 조회 API가 150 VU 부하에서 커넥션 풀 고갈로 실패율 100%, p95 30초 타임아웃 발생.
- **Action**: 커넥션 풀 증설(대기 지연), fetch join(페이징 붕괴), 캐싱(무효화 복잡도) 대안을 비교 검토하고, 병목 원인이 과도한 DB 왕복(1,500회)임을 확인한 후 IN 절 일괄 집계 쿼리로 DB I/O를 상수화함.
- **Result**: 동일 150 VU 부하에서 실패율 0%, p95 응답 시간 30s → 3.25s (9.2배 단축), 처리량 3.6 → 33.7 RPS 달성.
