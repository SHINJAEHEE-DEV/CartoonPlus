## 3. 🏷️ 서가 세부 번호 및 라벨링 규칙

1. **서가 위치 코드 포맷**: `[구역알파벳]-[책장번호]-[단번호]`
   - 예: `A-01-3` (A구역 1번 책장, 위에서 3번째 칸)
2. **서가 내 정렬 원칙**:
   - 구역 내에서는 무조건 **도서명 가나다순 (`ㄱ` ~ `ㅎ`)** 순서로 배열합니다.
   - 시리즈물은 1권부터 최신권까지 좌측에서 우측으로 순서대로 꽂습니다.
3. **라벨 스티커 출력 규격**:
   - 책장 측면/상단: `[A] 웹툰 구역 (A-01 ~ A-05)` (대형 안내판)
   - 책장 각 단(칸) 앞면: `A-01-1`, `A-01-2` ... (식별 스티커)

---

## 4. 🚶‍♂️ 현장 작업자 4단계 행동 수칙

```
[1단계: 시트 작성] ➜ [2단계: 책 이동] ➜ [3단계: 라벨 부착] ➜ [4단계: DB 갱신]
```

1. **1단계 (사전 계획)**: 해당 구역으로 이동할 도서 목록을 작업 시트에서 가나다순으로 확인합니다.
2. **2단계 (물리 이동)**: 대상 책들을 새 서가 칸(`A-01-1` 등)으로 이동하고 가나다순으로 정리합니다.
3. **3단계 (라벨 부착 & 검수)**: 책장 칸 번호 라벨이 올바른지 확인하고, 시트의 `실물 이동`과 `라벨 부착` 칸을 `Y`로 체크합니다.
4. **4단계 (DB 동기화)**: 해당 구역 1개 블록의 작업이 100% 완료되면 관리자/스태프 페이지에서 서가 번호와 장르를 일괄/순차 반영합니다.
