# 01: 검색 중심 Home과 매장 소개

**What to build:** 고객이 루트에서 바로 도서 검색을 시작하고, 기존 브랜드·시설 콘텐츠는 매장 소개에서 볼 수 있게 한다. 기존에 공유되거나 저장된 검색 주소도 계속 검색으로 작동하며, 검색 중심 Home에 맞는 정적 메타데이터를 제공한다.

**Blocked by:** None (can start immediately).

**Status:** complete

- [x] `/`에서 도서 검색 입력과 도서 목록을 제공하고, 기존 `Home` 소개 콘텐츠는 `매장 소개`에서 제공한다.
- [x] 일반 로고 클릭은 검색 Home으로 이동한다.
- [x] `/books`와 `/search`가 검색에 계속 접근하며 기존 고객 링크가 깨지지 않는다.
- [x] 검색 중심 Home의 제목·설명·사이트맵이 고객 검색 목적을 반영하고, 직원 경로는 계속 색인 제외된다.
- [x] 고객 탐색과 검색 동작을 외부 행동 기준으로 검증하고 프로덕션 빌드를 통과한다.
