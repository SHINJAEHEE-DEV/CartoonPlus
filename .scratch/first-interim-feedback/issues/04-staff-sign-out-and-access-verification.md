# 04: 직원 로그아웃과 접근 검증

**What to build:** 매장 전용 PC와 직원 개인 기기에서 직원이 로그인 상태를 명확히 종료할 수 있게 한다. 로그아웃 이후에는 보호된 운영 화면으로 돌아가도 인증·승인 확인을 다시 거쳐 운영 데이터를 볼 수 없게 한다.

**Blocked by:** 03: 숨은 직원 진입과 세션 복원.

**Status:** complete

- [x] Staff Shell에 명시적 로그아웃 동작을 제공한다.
- [x] 로그아웃은 저장된 인증 세션을 종료하고 고객 검색 Home으로 이동한다.
- [x] 로그아웃 뒤 Staff 보호 경로 재접근은 로그인 또는 접근 거부 상태를 보이며 운영 화면을 표시하지 않는다.
- [x] 승인된 직원 세션은 매장 전용 PC와 직원 개인 기기에서 브라우저 재시작 후 복원되는 기존 정책을 계속 충족한다.
- [x] 로그아웃과 보호 경로 차단을 외부 행동 테스트 및 PC·모바일 수동 검증으로 확인한다.
