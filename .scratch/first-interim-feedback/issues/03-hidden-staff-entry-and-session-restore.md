# 03: 숨은 직원 진입과 세션 복원

**What to build:** 고객 화면에는 직원 로그인 입구를 노출하지 않되, 직원은 로고를 3초 길게 눌러 진입할 수 있게 한다. 유효하고 승인된 Staff Account 세션은 대시보드로 바로 이동하고, 세션이 없거나 유효하지 않으면 로그인 화면을 제공한다. 직접 주소와 북마크도 같은 권한 확인을 사용한다.

**Blocked by:** 01: 검색 중심 Home과 매장 소개.

**Status:** complete

- [x] 고객 앱 셸에 공개 직원 로그인 링크가 표시되지 않는다.
- [x] 로고의 3초 길게 누르기와 동등한 키보드 접근이 직원 진입을 시작하며 일반 클릭의 검색 Home 이동을 유지한다.
- [x] 저장된 승인 Staff·Admin 세션은 직원 진입 시 대시보드로 이동한다.
- [x] 세션 없음, 만료·무효 세션, 대기·비활성화 Staff Account는 로그인 또는 접근 거부 상태로 처리되고 운영 화면을 표시하지 않는다.
- [x] `/staff` 직접 접근과 북마크도 같은 세션·승인 확인을 거친다.
- [x] 고객 앱 셸과 Staff 접근 흐름의 외부 행동 테스트를 통과한다.
