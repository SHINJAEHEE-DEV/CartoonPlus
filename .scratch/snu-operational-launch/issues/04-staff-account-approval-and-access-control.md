# 04: 직원 계정 가입·승인·권한 관리

**What to build:** 직원이 이름, 로그인 아이디, 비밀번호, 전화번호 끝 네 자리로 가입을 신청하고, 관리자가 승인·비활성화·임시 비밀번호 발급을 처리하는 안전한 운영 접근 흐름을 제공한다.

**Blocked by:** 01: 운영용 Supabase·GitHub Pages 환경 준비.

**Status:** blocked

- [ ] 가입 대기 직원은 운영 데이터 읽기·쓰기와 직원 화면 접근이 차단된다.
- [ ] 승인된 직원은 로그인 아이디와 비밀번호로 직원 운영 기능을 사용한다.
- [ ] 관리자는 직원이 할 수 있는 모든 운영 작업과 계정 승인·비활성화·임시 비밀번호 발급을 수행한다.
- [ ] 비활성화된 직원은 기존 세션을 포함해 운영 기능을 사용할 수 없다.
- [ ] 고객 공개 데이터와 Staff·Admin 권한 경계가 Supabase 정책으로 검증된다.
