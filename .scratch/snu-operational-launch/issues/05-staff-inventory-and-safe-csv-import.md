# 05: 직원 재고 관리와 안전한 CSV 갱신

**What to build:** 승인된 직원이 서울대입구역점 도서 재고를 추가·수정·보관·복구하고, Caspio CSV를 안전하게 가져와 고객 검색 결과를 최신 상태로 유지할 수 있게 한다.

**Blocked by:** 03: 고객 도서 검색과 서울대입구역점 초기 재고 공개; 04: 직원 계정 가입·승인·권한 관리.

**Status:** complete

- [ ] 직원이 도서명, 작가명, 장르, 보유 권수, 서가 위치를 등록·수정할 수 있다.
- [ ] 처음 등록한 재고만 신규 입고 도서로 표시되고, 30일 뒤 고객 목록에서 자동 제외된다.
- [ ] CSV의 같은 도서명·작가명 행은 권수와 서가 위치를 갱신하며 새 행은 추가된다.
- [ ] CSV가 기존에만 있는 재고를 자동 삭제하지 않고 직원 검토 대상으로 남긴다.
- [ ] 도서 재고를 보관·복구할 수 있고, 보관된 재고는 고객 검색에서 보이지 않는다.
