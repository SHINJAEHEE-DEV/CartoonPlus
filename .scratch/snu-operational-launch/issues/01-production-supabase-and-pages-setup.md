# 01: 운영용 Supabase·GitHub Pages 환경 준비

**What to build:** 서울대입구역점의 실제 운영 데이터와 직원 인증을 연결할 Supabase 프로젝트, 그리고 GitHub Pages 배포 환경을 준비한다. 이후 티켓이 안전하게 고객 공개 데이터와 승인된 직원 운영 데이터를 다룰 수 있는 출발점을 만든다.

**Blocked by:** None (can start immediately).

**Status:** ready-for-human

- [ ] 제품 책임자가 소유한 Supabase 프로젝트와 GitHub Pages 배포 권한이 준비되어 있다.
- [ ] 공개 가능한 앱 설정값과 비밀값의 보관·배포 방식이 분리되어 있다.
- [ ] 최초 관리자 계정을 수동 생성할 운영 절차가 준비되어 있다.
- [ ] GitHub Pages 주소에서 배포된 빈 앱을 열 수 있다.
