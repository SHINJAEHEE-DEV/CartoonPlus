# 02: 전환용 콘텐츠·자산 검증 준비

**What to build:** 서울대입구역점의 CSV, 매장 안내, 메뉴·요금, 진행 이벤트, 게임 목록, 브랜드 자산과 매장 사진을 전환에 사용할 수 있는 검증된 콘텐츠로 준비한다. 확인되지 않은 게임이나 이벤트는 고객에게 사실처럼 공개하지 않는다.

**Blocked by:** None (can start immediately).

**Status:** ready-for-human

- [ ] 서울대입구역점 CSV의 출처와 최신성을 확인한다.
- [ ] 주소, 전화번호, 영업시간, 주차·이용 안내, 메뉴·요금을 매장 기준으로 확인한다.
- [ ] 실제 게임 목록과 진행 이벤트를 확인하거나, 미확인 상태로 공개할 범위를 표시한다.
- [ ] 로고, 마스코트, 매장 사진의 사용 출처와 허가 상태를 기록한다.
