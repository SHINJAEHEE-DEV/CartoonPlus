# 06: 고객 입고 신청과 직원 처리 흐름

**What to build:** 고객이 개인정보 없이 도서 입고 신청을 제출하고, 승인된 직원이 내부 처리 단계를 관리해 입고 완료 도서를 신규 재고로 등록할 수 있게 한다.

**Blocked by:** 03: 고객 도서 검색과 서울대입구역점 초기 재고 공개; 04: 직원 계정 가입·승인·권한 관리; 05: 직원 재고 관리와 안전한 CSV 갱신.

**Status:** complete

- [x] 고객은 도서명과 선택적 작가명·희망 권수·메모만으로 도서 입고 신청을 제출한다.
- [x] 직원은 접수, 주문 완료, 입고 완료, 입고 불가 상태로 신청을 필터링하고 변경한다.
- [x] 입고 완료는 신청 정보를 사용해 신규 재고 등록을 시작하지만, 실물 재고를 자동 생성하지 않는다.
- [x] 등록 완료된 도서는 고객의 신규 입고 목록에 30일간 표시된다.
- [x] 고객 연락처와 고객별 처리 알림은 저장·전송하지 않는다.
