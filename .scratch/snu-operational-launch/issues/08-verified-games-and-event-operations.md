# 08: 검증된 게임 목록과 이벤트 운영

**What to build:** 고객에게는 현재 보유가 확인된 게임과 진행 중 이벤트만 보이고, 승인된 직원은 게임·이벤트를 생성, 갱신, 보관, 복구, 복사할 수 있게 한다.

**Blocked by:** 01: 운영용 Supabase·GitHub Pages 환경 준비; 02: 전환용 콘텐츠·자산 검증 준비; 04: 직원 계정 가입·승인·권한 관리.

**Status:** ready-for-agent

- [ ] 고객은 검증된 게임의 종류, 제목, 인원, 장르, 이용 가능 여부를 확인한다.
- [ ] 게임 데이터가 아직 검증되지 않았을 때 고객 화면은 점검 중 상태를 표시한다.
- [ ] 직원은 게임을 검증 상태로 등록·수정·보관·복구할 수 있다.
- [ ] 고객은 현재 기간의 공개 이벤트만 보고, 종료일 다음 날부터는 보지 않는다.
- [ ] 직원은 이벤트를 생성·수정·보관·복구하고 종료 이벤트를 복사해 새 이벤트 초안으로 만들 수 있다.
