# 09: 매장 방송·예약 방송·실행 기록

**What to build:** 승인된 직원이 한국어 방송 프리셋과 직접 입력 방송을 실행하고, 매장 PC에서 자동 예약 방송을 관리하며 실패를 즉시 재생할 수 있게 한다.

**Blocked by:** 01: 운영용 Supabase·GitHub Pages 환경 준비; 04: 직원 계정 가입·승인·권한 관리.

**Status:** ready-for-agent

- [ ] 직원은 한국어 방송 프리셋과 직접 입력 문구를 즉시 재생하고 현재 상태를 확인한다.
- [ ] 직원은 매일 반복, 요일 반복, 일회성 예약 방송을 생성하고 각 예약을 켜거나 끈다.
- [ ] 매장 PC 브라우저가 실행 중일 때 활성 예약 방송이 별도 시작 점검 없이 정해진 시각에 재생을 시도한다.
- [ ] 방송 실행 기록에 대기, 성공, 실패와 실행 시각이 남는다.
- [ ] 실패한 방송은 직원이 운영 화면에서 즉시 다시 재생할 수 있다.
