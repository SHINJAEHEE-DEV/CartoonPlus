# 10: 서울대입구역점 전환 검증과 공개

**What to build:** 전환일 전에 고객 모바일·데스크톱과 매장 카운터 PC에서 실제 운영 흐름을 검증하고, GitHub Pages 공개 주소를 서울대입구역점의 새 운영 표면으로 전환한다.

**Blocked by:** 02: 전환용 콘텐츠·자산 검증 준비; 03: 고객 도서 검색과 서울대입구역점 초기 재고 공개; 04: 직원 계정 가입·승인·권한 관리; 05: 직원 재고 관리와 안전한 CSV 갱신; 06: 고객 입고 신청과 직원 처리 흐름; 07: 브랜드 홈·매장 안내·메뉴·요금 운영; 08: 검증된 게임 목록과 이벤트 운영; 09: 매장 방송·예약 방송·실행 기록.

**Status:** ready-for-agent

- [ ] 타입 검사, 자동 테스트, 프로덕션 빌드, GitHub Pages 배포가 모두 성공한다.
- [ ] 고객 모바일과 데스크톱에서 홈, 검색, 입고 신청, 게임, 이벤트, 매장 안내, 메뉴·요금 흐름을 점검한다.
- [ ] 카운터 PC에서 Staff·Admin 권한, 재고·CSV·입고 신청·콘텐츠·방송 흐름을 점검한다.
- [ ] 실제 스피커에서 한국어 방송과 예약 방송을 검증하고 실패 재생 흐름을 확인한다.
- [ ] 전환 데이터·이미지 출처·공개 정보가 최종 확인되고, GitHub Pages 주소가 고객에게 안내된다.
