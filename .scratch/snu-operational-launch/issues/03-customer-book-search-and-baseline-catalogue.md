# 03: 고객 도서 검색과 서울대입구역점 초기 재고 공개

**What to build:** 고객이 실제 서울대입구역점 재고에서 도서명·작가명·초성으로 도서를 찾아 권수와 서가 위치를 확인하고, 결과가 없으면 도서 입고 신청으로 이동할 수 있게 한다.

**Blocked by:** 01: 운영용 Supabase·GitHub Pages 환경 준비.

**Status:** blocked

- [ ] 검증된 CSV 재고가 Book과 BookInventory로 안전하게 저장된다.
- [ ] 도서명·작가명 부분 검색, 공백 무시 정규화, 초성 검색이 동작한다.
- [ ] 초성만이 아닌 검색어와 비어 있거나 기호뿐인 검색어가 관련 없는 도서를 반환하지 않는다.
- [ ] 결과 카드에 도서명, 작가명, 장르, 보유 권수, 서가 위치가 표시된다.
- [ ] 결과가 없을 때 고객이 연락처 없이 도서 입고 신청을 시작할 수 있다.

## Comments

- 2026-09-07: 고객 검색 화면, 공백 무시·초성 검색, 무결과 입고 신청 시작 화면, Supabase 공개 카탈로그 스키마를 구현했다. 기준 CSV의 `number`는 책장 번호이며, 제목 끝의 공백 뒤 숫자는 현재 보유한 마지막 권이다. 고객 화면에는 `책장 n번`, `1~n권`으로 표시한다. 책장 안의 칸 정보와 Supabase 초기 적재가 완료되면 추가 갱신한다.
