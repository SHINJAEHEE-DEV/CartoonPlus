# 07: 브랜드 홈·매장 안내·메뉴·요금 운영

**What to build:** 고객이 카툰플러스의 브랜드와 서울대입구역점 이용 경험을 이해하고, 매장 안내·메뉴·요금을 신뢰할 수 있게 제공하며, 직원이 공개 정보를 최신 상태로 관리할 수 있게 한다.

**Blocked by:** 01: 운영용 Supabase·GitHub Pages 환경 준비; 02: 전환용 콘텐츠·자산 검증 준비; 04: 직원 계정 가입·승인·권한 관리.

**Status:** complete

- [x] Home은 제공된 와이어프레임의 색상·둥근 카드 분위기를 따르며 카툰플러스를 소개한다.
- [x] 고객 메뉴에서 Home, 도서 검색, 게임 목록, 이벤트, 매장 안내, 직원 로그인으로 이동할 수 있다.
- [x] 주소, 영업시간, 전화번호, 주차·이용 안내, 메뉴와 요금이 모바일과 PC에서 읽기 쉽게 표시된다.
- [x] 승인된 직원이 공개 매장·메뉴·요금 정보를 수정하면 고객 화면에 반영된다.
- [x] 기능 아이콘은 하나의 선형 SVG 체계를 사용하고, 사용 허가된 브랜드·매장 사진만 표시한다.
